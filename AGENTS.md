# Repository guidelines

Keep reusable logic inside the named package under src/. No generic src imports or dependencies on the integration repository are allowed. Maintain the documented acyclic component graph. Never put weights, datasets, encoder caches or generated logs in Git. Preserve token IDs, checkpoint state-dictionary keys and format versions. Run focused offline tests using the existing environments; do not initiate production training or download models without an explicit request. Record migration decisions centrally in ../LLM-From-Scratch/documentation/training/SESSION_DECISIONS.md. Preserve the visible Kitty viewer requirement for operator-launched training: the built-in 100x22 viewer by default, or an integration-supplied viewer via `LLM_TRAINING_VIEWER_COMMAND` (JSON argv, receives `--status`/`--marker`, must attach within 15 s).
